# 红果短剧

<img src="images/app-icon.png" width="96" alt="播放三角环图标" />

独立 macOS 桌面客户端，原生播放、默认深色。无需安装手机端 App。

## 下载

在 [最新版 Release](https://github.com/JialaoLiu/hongguo-mac-release/releases/latest) 下载 `HongguoDrama-0.4.0-arm64.dmg`，将 **红果短剧.app** 拖入 Applications。

支持 macOS 26 及以上、Apple Silicon（arm64）。Java、签名运行组件和媒体处理组件已随应用携带；普通使用无需单独下载 `hongguo-native-runtime-macos-arm64.zip`。

## 桌面体验

- 炭黑与橙红配色、宽侧栏整行导航；支持深色、浅色与跟随系统。
- 发现、排行榜、探索、收藏、历史；片单滚动自动批量追加。
- 完整选集、同系列其他季；有历史记录自动续播，未看过的作品等待手动播放。
- 自定义画质、倍速、进度和音量；系统画中画、视频全屏及双指音量／亮度控制。
- 未登录也能只读查看评论、点赞数和楼中楼，滚动自动加载。
- 左上角独立桌面标记一键返回首页，重置搜索与筛选。

## 仍在跟踪

| 编号 | 问题 | 当前进展 |
| --- | --- | --- |
| HG-048 | Intel 兼容候选的签名服务崩溃 | macOS 15 原生 Intel 测试机及 Rosetta 均复现 SIGBUS。Java、核心检查及媒体解码已通过，签名服务仍阻断在线播放，尚无 Intel 包 |

| HG-057 | 切回应用后弹幕停留在原位置 | 0.7.0 加入独立播放时钟和应用激活同步；渲染检查通过，完整应用冻结场景尚未取得稳定复现 |
| HG-054 | 弹幕滚动顿挫 | 0.7.0 改为连续动画、缓存纹理并限制重复内容，完整播放体验继续观察 |
| HG-056 | 倍速时弹幕从画面中途出现 | 0.7.0 提前安排按视频时间启动的动画，1／2／3 倍入场检查通过，继续观察完整播放场景 |

## 最近已修复的重点问题

| 编号 | 问题与处理 | 验证结果 |
| --- | --- | --- |
| HG-058 | 下载地址空响应造成英文解析错误；下载进度为零 | 转为中文错误、暂时失败最多尝试三次；真实字节与速度回调；原失败三集可播放，本机原 8 个失败任务恢复，第九季 99 集全部完成 |
| HG-055 | 播放控制栏两行且占用空间 | 普通窗口与全屏已实际核验为紧凑单行；0.7.0 移动清晰度／倍速并提供悬停快捷键说明 |
| HG-053 | 自动下一集把选集滚回顶部 | 自动 75→76 集保持滚动位置；0.7.0 自动保持当前集可见，82→83 集仍保持原位置 |
| HG-051 | 跟随系统时设置文字与背景不一致 | 原机浅色／深色切回跟随系统已核验；0.6.2 修复 |
| HG-033、HG-042 | 读取失败后空数据覆盖下载记录 | 损坏及不可读记录隔离测试通过，原记录保留并备份 |
| HG-034 | 删除／移动文件后同集无法重新下载 | 失效文件可重新排队；有效文件不会重复下载 |
| HG-030、HG-039、HG-040 | 画中画换集、旧集恢复及倍速偏好问题 | 在线自动下一集仍保持画中画，切集等待阻止旧视频恢复，原生暂停恢复保留倍速 |
| HG-031、HG-043 | 检查更新失败与旧系统安装不兼容新版 | API 回退、真实升级与数据保留已核验；安装前检查最低系统要求 |
